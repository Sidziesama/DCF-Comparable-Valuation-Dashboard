# Methodology and controls

The pipeline normalizes public SEC facts into annual, quarterly, and LTM histories; builds Bear, Base, and Bull operating forecasts; links income statement, balance sheet, cash flow, and FCFF; and applies Gordon-growth and exit-multiple DCF methods. Comparable-company outputs, a football field, and bounded reverse-DCF solvers supplement intrinsic valuation.

Controls cover statement balance, cash, debt, equity and PP&E roll-forwards, FCFF reconciliation, scenario ordering, WACC versus terminal growth, and terminal-value concentration. Available hard checks must pass for the core pipeline to complete. Missing observations remain unavailable instead of being invented.

The recommendation is deterministic and policy-based. It uses valuation, downside, evidence coverage, evidence quality, thesis confidence, and model health. Generated claims retain evidence identifiers and the report includes a source appendix. This is an analytical demonstration, not investment advice.
